Keep Arclora close

Open it like an app.

Arclora is a web app. You can use it in your browser, or add it to your phone’s home screen for quick access. It updates from the website when you open it online.

On iPhone or iPad
  1. Open this page in Safari. If it opened inside another app, use that app’s share menu to open it in Safari.
  2. Tap Share, then scroll and choose Add to Home Screen.
  3. Turn on Open as Web App if it appears, then tap Add.
On Android
  1. Open this page in Chrome.
  2. Tap the three-dot menu, then choose Install and create shortcut or Install app.
  3. Follow the prompt to add Arclora to your device.
On another device
  1. Open the page in a modern browser and look for an install option in its menu. You can always use Arclora directly from this link.
